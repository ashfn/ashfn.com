# ashfn.github.io

Static files for [ashfn.com](https://ashfn.com).

The source is in [ashfn/ashfn.com](https://github.com/ashfn/ashfn.com).
Edit and build there, then copy the contents of `dist/` here and commit and push.
Keep `.nojekyll` and `CNAME` in the export.

GitHub Pages serves the root of the `main` branch using the domain `ashfn.com`.
No server or package installation is needed here.

This README comes from `public/README.md` in the source repository.
